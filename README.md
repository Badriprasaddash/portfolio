# Academic Website: Dr. Badri Prasad Dash

A responsive academic and research portfolio website created for **Dr. Badri Prasad Dash**, specialist in **International Geopolitics**.

---

## File Structure
- [`index.html`](index.html): Semantic HTML5 structure containing Hero, Biography, Academic Qualifications Timeline, Research Interests Pillars, Selected Publications with Category Tabs, Teaching & Lectures, Contact Form & Academic Links, and Footer.
- [`style.css`](style.css): Academic visual styling with typography (Playfair Display, Cinzel, Plus Jakarta Sans), dark/light theme variables, responsive design, and print stylesheet for generating a CV.
- [`script.js`](script.js): Dynamic client-side logic for dark/light mode toggle (with localStorage), mobile responsive menu, scrollspy navigation, publications filter, and interactive contact form.

---

## How to View and Run
1. Double-click or open [`index.html`](index.html) in any web browser (Google Chrome, Microsoft Edge, Firefox, Safari).
2. Alternatively, run a lightweight local HTTP server if desired:
   ```bash
   # Python
   python -m http.server 8000
   ```
   and navigate to `http://localhost:8000`.

---

## Key Features
- **Responsive Layout**: Optimized for mobile phones, tablets, laptops, and ultra-wide desktops.
- **Dark & Light Mode**: Seamless switcher with persistent user preference storage.
- **Academic Timeline**: Highlights doctoral and postgraduate training from University of Madras and Utkal University.
- **Curated Research Clusters**: Showcases international geopolitical domains such as Indo-Pacific strategy, maritime chokepoints, foreign policy, and multilateral institutions.
- **Print CV Functionality**: Styled specifically for generating clean, printable academic CVs directly from the browser (`Ctrl + P` / `Cmd + P`).
